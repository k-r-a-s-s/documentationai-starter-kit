## Overview

## Fundraising Dashboard and Tracking

Monitor your progress from anywhere.

Integrate the dashboard SDK for custom apps:

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  import { HighImpactSDK } from '@highimpact/athletes-sdk';

  const sdk = new HighImpactSDK({ apiKey: 'YOUR_API_KEY' });
  const dashboard = await sdk.dashboard.fetch('user-123');
  console.log(dashboard.totalRaised); // e.g., 1500
  ```
  ```python
  from highimpact import HighImpactSDK

  sdk = HighImpactSDK(api_key="YOUR_API_KEY")
  dashboard = sdk.dashboard.fetch("user-123")
  print(dashboard.total_raised)  # e.g., 1500
  ```
</CodeGroup>

Set goals and automate updates.
