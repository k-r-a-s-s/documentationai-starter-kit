## Upgrade Instructions

Follow these steps to upgrade your High Impact Athletes integration to the latest version.

<Steps>
  <Step title="Backup Data" icon="database">

    Export your athlete data and race configurations.

````bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  https://api.example.com/v1/export > backup.json
````

  </Step>
  <Step title="Update SDK" icon="download">

    Install the latest SDK version.

    <Tabs>
      <Tab title="npm" icon="package">
````bash
npm install high-impact-athletes-sdk@1.2.0
````
      </Tab>
      <Tab title="Python" icon="code">
````bash
pip install high-impact-athletes-sdk==1.2.0
````
      </Tab>
    </Tabs>

  </Step>
  <Step title="Run Migrations" icon="settings">

    Apply database migrations.

````bash
npx high-impact-athletes migrate
````

  </Step>
  <Step title="Test Integration" icon="check-circle">

    Verify endpoints like leaderboards and donations.

  </Step>
</Steps>
